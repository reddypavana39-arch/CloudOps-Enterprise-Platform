

# CloudOps Enterprise Platform

## Project Overview
The CloudOps Enterprise Platform is a cloud-native DevOps project that demonstrates infrastructure provisioning, networking, security, containerization, CI/CD, monitoring, and cloud deployment using AWS, Docker, Kubernetes, Terraform, and Jenkins.

## Technologies Used
- AWS
- Terraform
- Docker
- Kubernetes
- Jenkins
- Git & GitHub
- Linux
- CloudWatch
